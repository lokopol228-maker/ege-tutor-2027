# ОШИБКА P1001 = НЕТ СВЯЗИ С БАЗОЙ

Это НЕ про GROQ. Чиним DATABASE_URL.

## Сделай на Render:

1) Вверху/слева открой проект ege-tutor-2027
2) Найди сервис Postgres (часто называется ege-tutor-db)
   - если базы НЕТ → New → Postgres → Free → Create
3) Зайди в Postgres → вкладка Connect / Info
4) Скопируй Internal Database URL
   (строка начинается с postgresql://...)
5) Открой Web Service ege-tutor-2027 → Environment
6) Найди DATABASE_URL
   - если нет → Add Environment Variable
   - Key: DATABASE_URL
   - Value: вставь Internal Database URL
7) Проверь также:
   - ADMIN_EMAIL
   - ADMIN_PASSWORD
   - NEXTAUTH_URL (после первого успешного деплоя = URL сайта)
8) Save → Manual Deploy → Deploy latest commit

GROQ/GEMINI на Render не трогай.
