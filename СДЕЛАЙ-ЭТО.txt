# ЧТО СДЕЛАТЬ ТЕБЕ (я уже убрал сломанную Postgres)

База теперь встроена (SQLite). Render Postgres больше не нужна.

## 1) Environment на Render
Открой ege-tutor-2027 → Environment → Edit

Поставь/проверь:
- DATABASE_URL = file:./prisma/data/prod.db
  (замени старую postgresql://... на эту строку!)
- ADMIN_EMAIL = твой email
- ADMIN_PASSWORD = твой пароль (от 8 символов)
- NEXTAUTH_URL = пока можно оставить пустым, потом впишешь URL сайта
- GEMINI / GROQ — не трогай / можно удалить

Save Changes

## 2) Deploy
Manual Deploy → Deploy latest commit
Дождись зелёного статуса (не Failed)

## 3) После успеха
Скопируй URL сайта (типа https://ege-tutor-2027.onrender.com)
Environment → NEXTAUTH_URL = этот URL
Save → ещё один Deploy

## 4) Войти
Открой сайт → email/пароль → кабинет
Ключ ИИ (если будет) — в «Настройки ИИ» на сайте

Важно: на бесплатном Render прогресс может сбрасываться после долгого сна сервиса.
Для постоянной базы потом можно подключить Neon — скажи, помогу.
