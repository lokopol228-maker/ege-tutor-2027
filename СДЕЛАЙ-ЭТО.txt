# ТЕБЕ ОСТАЛОСЬ 3 ШАГА (Gemini недоступен в РФ — берём Groq)

Я уже сделал сайт, Node, Git и локальный git.
Gemini AI Studio у тебя открыл страницу регионов = ключ Gemini сейчас не получить.
Делаем бесплатный ключ через Groq.

## Шаг A — ключ ИИ через Groq (3 минуты)
1. Открой: https://console.groq.com/keys
2. Войди (Google/GitHub)
3. Create API Key → скопируй в Блокнот
4. Это будет `GROQ_API_KEY`

## Шаг B — GitHub (3 минуты)
1. Открой: https://github.com/new
2. Name: `ege-tutor-2027`
3. Private → Create repository
4. Пришли мне ссылку:
   https://github.com/ТВОЙ_НИК/ege-tutor-2027.git
Я сам загружу код.

## Шаг C — Render (после загрузки кода)
1. https://dashboard.render.com → New → Blueprint → репо `ege-tutor-2027`
2. Заполни:
   - ADMIN_EMAIL
   - ADMIN_PASSWORD
   - GROQ_API_KEY  ← ключ из шага A
3. Deploy
4. Потом поставь NEXTAUTH_URL = адрес сайта и Redeploy
